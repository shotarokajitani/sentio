# 04 Act層（配信・行動・還流）

統制原則: 「毎日見えるが、毎日読まされない」。プッシュは緊急度で規律、プルは無制限。

## Day0初回調査バッチ（登録10分以内）
専用走査4種（競合乖離・健全性・機会マッチ・懸念仮説）でcandidate生成→フルハーネス1回（調査予算の獲得コスト例外・全プラン標準）。
8ブロック: ①外から見た自社（analyze-urlを競合にも実行し装備差分）②評判の座標（Places自社vs競合）
③サイト健全性（SSL期限・速度）④公的記録の非対称（gBizINFO: 競合の補助金採択・認定・調達）
⑤今使える機会（jGrants締切順トップ3）⑥業界・地域の中の位置（e-Stat・日銀。店舗型のみ商圏・人流を自動挿入）
⑦初期懸念への初期仮説（登録時懸念×全ブロック交差）⑧見えるようになる地図（接続別カバレッジ予告）
強い2〜3個をDay0、残りは初週ドリップ（パルスに1日1個）。
Day0のEvaluator変形: 基準2は「出所明示」に読替。誠実さ要件（外部データのみの暫定推察と明示）を追加。断定禁止。

## デイリーパルス（毎朝・3行・10秒）
昨日の事実2行＋状態1行（平常/watching経過）。異常日のみ4行目。ベースライン新規成立も1行通知。
チャネル: LINE/Chatwork/Slack（オンボーディングで選択）。

## 即時アラート
高速路専用。事実＋確認先リンクのみ、解釈なし。静音時間帯23–6時は集約翌朝、進行中損失（サイトダウン等）のみ例外。
例外リストは変更可能だがデフォルトで機能（ゼロ入力）。

## 週次「今週の会社」（主戦場・メール内完結）
構成順固定: ①状態ダイジェスト（3秒で掴める意味の文）②Finding 0〜2件 ③続報 ④安定＋カバレッジ ⑤拡張ナッジ最大1行
（統制: 同一ツール2週間に1回。優先度①回答起点＞②Finding起点＞③定期）。
Findingテンプレ: 【見えたこと】→【根拠】→【考えられること】→【選択肢】＋「判断は◯◯さんがされることですが」→【ワンタップ】
（Evaluator基準1・2・4と一対一対応）。従業員名を含むFindingはケア文脈の文型のみ。

## 月次レーダー
競合の公的な動き（gBizINFO・サイト差分の月次総括）＋自社が使える補助金（締切順）＋四半期傾向。問いは載せない。

## ワンタップ実行（初期4種）
①1on1カレンダー仮登録 ②Chatwork/Slack声かけ文面下書き
③従業員1タップ確認（経営者承認→botが1問・選択肢2〜3・30秒。同一従業員2週間に1回上限。回答はdialogue）
④経過を見る（watching指定・続報予約）
共通規律: Sentioは何も勝手に送らない・登録しない。全て下書き/仮登録で停止、最終確定は経営者のタップ。
実行・不実行は較正ループへ。

## 「Sentioに聞く」（プル）
パルスと同チャネル＋Web。記憶パケット編成器経由。回答内の事実は証拠イベント遡及可能（基準2を会話にも適用）。
質問はnarrativesへ還流。未接続領域は定型: 「そこはまだ見えていません。◯◯を接続すると見えるようになります」。

## 運用の自己防衛
- adaptive cadence: 反応ゼロ継続→形式・時間帯・チャネルを自動調整→なお無反応はオンボーダーへ内部アラート
- データ腐敗監視: コネクタ鮮度をmonitorイベント化。鮮度切れはカバレッジから即除外＋再接続ワンタップ
- 冷間期（Week2〜4）: 確度表示を必ず付け、事実系・続報系・カバレッジ報告に寄せる（賢く見せるより正直に育つ）
- 透明性ページ: 「見ているもの・見ていないもの」一覧を経営者・従業員双方が閲覧可能（3点開示の実装）

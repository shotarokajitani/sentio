# eval/ — エンジン評価スイート（賢さの回帰テスト）
- golden/: 入力固定（合成会社タイムライン断片＋記憶パケット）→ 期待Finding の対。1ケース=1ディレクトリ
- 実行: pnpm run eval:engine → 検知率・誤検知率（陰性コントロール含む）・ルーブリック採点を出力
- 合格線はスライス契約が定義（slice-01: 陽性7件中6以上・誤検知≤2）
- prompts/ の変更PRは本スイートの結果添付が必須（prompts/README参照）
- 実顧客データをゴールデンセットに入れない。合成会社のみ
- ゴールデンセットにはlangフィールドを最初から持たせる（スライス1はjaのみ。多言語展開時にLauda形式と互換）

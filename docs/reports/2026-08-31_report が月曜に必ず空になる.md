# `/report` は毎週月曜に必ず空になる（2026-08-31・検収者）

**Google 審査の4〜6週間、毎週2日ほど「空のレポート」を審査者に見せる状態になっている。**
提出済みのテスト資格情報の記述と食い違うので、審査中に踏まれる可能性が高い。

## 何が起きているか

2026-08-31（月）00:35 に本番の `/report` を開いたら、こう出ていた。

```
この週に予定がありません
カレンダーに予定が無かったか、まだ同期されていない可能性があります。
```

先週（8/24〜8/30）は 会議5件 / 総会議時間5時間 / のべ出席者3人 が出ていた。
**バグではない。当週が変わっただけである。**

## 2つの仕様が噛み合っていない

| 仕様 | 出所 |
| --- | --- |
| `/report` は**当週固定**（期間の切り替え UI は非スコープ） | 契約 `slice-weekly-report.md` |
| `sync-connections` は **`timeMin = now - 7日` / `timeMax = now`** | `supabase/functions/sync-connections/index.ts:188-196` |

**`timeMax = now` なので、未来の予定は同期されない。**
初回連携（`callback/google/route.ts:130`）も `timeMax = now` で同じである。

したがって:

- **月曜の朝は、当週にまだ過ぎた予定が無いので必ず空**
- 週が進むにつれて1件ずつ埋まる
- 金曜には満ちるが、翌月曜にまた空に戻る

**毎週この鋸歯が出る。**

## 審査への影響

提出済みのテスト資格情報にこう書いてある。

> A Google Calendar is already connected to this account, so the weekly report
> at https://sentio-ai.jp/report **is populated when you sign in.**

**月曜・火曜午前に審査者がログインすると、この記述は嘘になる。**
審査は4〜6週間かかるので、その窓は5〜6回訪れる。

## 応急処置（2026-08-31 実施済み）

連携中のカレンダー（`shotaro.kajitani@mdc-diseno.com`）に当週の予定5件を作成した。

| 予定 | 日時（JST） |
| --- | --- |
| 週次経営会議 | 8/31（月）10:00–11:00 |
| 新規パートナー商談（2回目） | 9/1（火）14:00–15:30 |
| 開発デイリー | 9/2（水）09:30–10:00 |
| 顧客定例 — 導入レビュー | 9/3（木）13:00–14:00 |
| 採用面談（2次） | 9/4（金）16:00–17:00 |

合計 60+90+30+60+60 = **300分 = 5時間**（先週と同じ設計値）。

**ただしこれは応急処置にすぎない。** 作成時点（月曜 00:40）では5件とも未来なので、
**今日の同期では1件も入らない。** 火曜以降、過ぎた分から順に入る。
**来週の月曜にはまた同じことが起きる。**

## 提案（**未着手・人間の判断待ち**）

**当週が0件のとき、直近の実績がある週を出す。**

```
今週の会社
今週はまだ予定がありません。直近の実績を表示しています。
8月24日 〜 8月30日          ← ラベルで期間を明示する
会議        5件
総会議時間  5時間
のべ出席者  3人
```

- **判断基準に合う。** 「空の箱」を見せるより「直近の状態」を見せる方が、
  経営者の頭に絵が浮かぶ
- **月曜の崖が消える。** 審査期間中も常に中身がある
- **嘘にならない。** どの週を見せているかをラベルで明示する

**ただし `/report` の意味が変わる**（契約 スライスW は「当週固定」を明示的な決定として置いた）。
**変えるなら契約の更新とセットである。勝手に変えない。**

代案として「直近4週間を並べる」もあるが、画面が重くなる。
**まずはフォールバック1段が安い。**

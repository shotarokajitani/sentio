## 何を売るのか（枠の対象）

`_shared/budget.ts` が既に持っている**唯一の枠**は、フルハーネス調査の日次起動上限である。

フルハーネス（Planner→Generator→Evaluator）は LLM を最も使う経路で、
**原価がそのまま乗る唯一の場所**でもある。ここを枠にするのは、
売る側の都合（原価）と買う側の理解（調べてくれる回数）が一致する数少ない指標だからである。

**枠にしないもの。**

|                      | 理由                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------- |
| 取り込むデータ源の数 | 増えるほど製品が効く。絞ると「入力を要求しない」の逆を向く                               |
| 保存期間             | privacy §6 で24ヶ月と公開済み。プランで変えると約束が揺れる                              |
| 配信の回数           | 送るのは Sentio の判断であって利用者の操作ではない。絞ると気づけない日ができる           |
| ライトパス           | `spec/03` が「上限超過はライトパス降格」と定めている。**降格先を絞ると降格が成立しない** |

## 価格の根拠

`06_positioning.md` が置いている代替コストは3つある。

| 代替手段               | 正本の試算                        |
| ---------------------- | --------------------------------- |
| 5名×毎日30分の朝会     | 年180万円（時給3,000円）          |
| **5名×毎日15分の日報** | **年90万円**（時給3,000円）← 最小 |
| 管理職を1人増やす      | 年600万円規模                     |

**最も小さい代替コストは日報の年90万円である。** ここを上限に置くのが安全側で、
「日報をやめる分で払える」が説明として最も通りやすい。

## 決定

**2段構成。**

| プラン   | 月額      | `fullRunsPerDay` |
| -------- | --------- | ---------------- |
| **試用** | 0円       | 3                |
| **標準** | **3万円** | 10               |

**3万円の根拠**は「日報の年90万円の4割以内に収める」である。年36万円。
正本が持っている**最小の**代替コストに対して、明確に下回る位置に置いた。

**拡張プランは置かない。** 外部顧客がまだ居ない段階で3段目を置くと、
「大きい会社に何が必要か」を**推測で決める**ことになる。欲しい人が現れてから作る。
Stripe の商品も少ない方が壊れにくい。

**試用を3回にしたのは、`budget.ts` の docstring が
「3 にすると S-3-2（合成会社の一気通貫）が上限に当たる」と警告しているためである。**
テストが素通しできる余裕は標準（10）が持つので、試用は3で構わない。

**価格は計算ではなく探りである。** 顧客が0社の段階で相場は見ていない。
最初の数社で見直す前提で置いている。

## 上限に当たったときの見せ方

**週次レポートに1行出す。**「今週は◯件を簡易調査に切り替えました」。

**別途の通知は送らない。** これは利用者が今すぐ動くべきことではなく、
「何も勝手に送らない」との線引きも微妙になる。
一方で**黙っていると、気づかないうちに調査が薄くなる**ので、週次には必ず出す。

## 購読が無い会社の扱い

**課金が動き出したら、購読の無い会社は試用に落ちる。**
いまは購読という概念自体が無いため、既定を標準にしてある——
ここを試用にすると、**いまいる会社の枠を黙って 10 → 3 に減らす**ことになる。
Stripe を繋いだ時点で `DEFAULT_PLAN` を `TRIAL_PLAN` に倒す。

## まだ決めていないこと

1. **年額を置くか。** 置くなら Stripe の商品構成が変わる
2. **枠の 10 という値そのもの。** 暫定であることは元から `07_open_items.md` に登録済みで、
   プランの決定はそれを追認していない
3. **試用の期間。** 「ずっと 0円/3回」なのか「N日で切れる」のか。
   期間を置くなら Stripe 側の trial 設定を使うか、こちらで持つかも決める

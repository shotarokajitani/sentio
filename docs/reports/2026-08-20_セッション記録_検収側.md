**「ローカルで回せる検査の集合 ≠ 完了判定に必要な検査の集合」**というずれが根にある。

### 1-5. Prettier による破壊の正体

`~/.claude/settings.json:44` のグローバルフック。

```json
{ "matcher": "Write|Edit",
  "hooks": [{ "type": "command",
              "command": "npx prettier --write . 2>/dev/null; true" }] }
```

`--write .` が**リポジトリ全体**を対象にするため、編集と無関係な
`pnpm-lock.yaml`（5061行）/ `src/i18n/ja.ts` / `docs/checklists/env-diff.md` が
書き換わっていた。`2>/dev/null; true` で失敗も見えない。

`env-diff.md` の破壊は**非冪等**で、1回あたりインデントが +4 押し下がる
（元6 → 14 → 34 を実測）。ずれが3以上になると終了フェンスが閉じず、表がコードブロックに飲まれる。

**グローバル設定なので Sentio に閉じない。** 他プロジェクトの lockfile・生成物・
インデント依存の Markdown も同じ経路で壊れる。

| 作業ツリー3ファイルの差分は **pnpm のバージョンドリフト** | **誤り。** `lockfileVersion` の行は diff に出るが**値は 9.0 のまま**でクォート種別だけ。`packageManager: pnpm@11.21.0` で既に固定済み。原因は Prettier |

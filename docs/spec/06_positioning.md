# 06 ポジショニング（防衛線9本・メリット言語）

## 防衛線（対 代替手段）

1. 対ChatGPT: 「聞けば答える」vs「聞かなくても見ている」。汎用AIチャットは究極の入力依存型。
   堀は知能ではなく接続・記憶・能動性（＋検証済み解釈）。日本SMEスタックへの深い統合は汎用大手が優先しない。
2. 対会議: 会議の4機能（吸い上げ/早期発見/記録/判断）のうち3つを高品質代替し、判断を純化。
   「Sentioは会議を消すのではない。会議を『判断だけの場』に純化する」。5名×毎日30分朝会≒年180万円（時給3,000円試算）。
3. 対BI: 「ダッシュボードは見に行く人がいる会社のための道具。Sentioは見に行く人がいない会社に向こうから来る」。
4. 対税理士: 「税理士は過去の数字の専門家。Sentioは数字になる前の変化の番人」。競合でなくチャネル候補。
5. 対「うちは見えている/番頭がいる」: 毎日会議でも挙がらない（どうだい？事例）。番頭は忖度する、データはしない。
   「一番見えていないのは、社長自身かもしれない」。
6. 対サーベイ: 「アンケートには良い顔ができる。行動データに良い顔はできない」。
7. 対SFA/CRM（Salesforce等）: **Sentio の判断基準（アンチ・セールスフォース）を裏側から言い切った防衛線。迷ったらここへ戻る。**
   「入力させてから見る」vs「入力させずに見る」。SFAが根付かない原因は機能ではなく**入力率**で、
   入力率を上げる施策（研修・催促・評価連動）はすべて現場の時間を奪う。
   Sentioは**入力率0%を前提に設計されている**（入力を求めた時点で設計が壊れる）。
   「使われないSFAの隣で、Sentioは誰も使わなくても動いている」。
8. 対日報・週報／管理帳票: 「管理のために書かせる」vs「**管理そのものを仕組みにする**」。
   報告を書く時間は原価であり、書かれた報告は**書き手が見せたいものに寄る**。
   5名×毎日15分の日報≒年90万円（時給3,000円試算）。
   「報告を集めるのをやめる。集まる状態にする」。
9. 対「管理職を増やす／目を増やす」: 「見る人を増やす」vs「**見る仕事を人から外す**」。
   管理職を1人増やすのは年600万円規模の固定費だが、増えた目も結局は**現場の報告に依存する**。
   Sentioは目を増やすのではなく、**目が要らない状態を作る**。

## 構造堀（時間とともに強くなる）

記憶の複利 / 横断パターンのネットワーク効果 / コンプライアンス資産（申請の束＝時間の壁）/
「監視しないAI」の先行規範（透明性ページで検証可能に）/ オンボーダーの泥臭さ（大手がやらない仕事）。

## メリット言語（対外・「見える」系で統一）

報告されない問題が、見える。/ あなたが気づく前に、気づく。そして、その後まで見届ける。/
聞けば30秒、会社のことが分かる。/ 会議は、判断だけに使えばいい。/ 入力ゼロ。それでも、見える。/
会社の記憶を、社長の頭の外に。/ 知らせが来ない日は、安心していい日。
※LPで承継・離職コスト等の統計を添える場合は最新出典を要確認。

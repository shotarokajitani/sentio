## 3. 発見した重大事項

### 3-1. S-5 が赤い CI のまま完了扱いになっていた（run 32282055630）

`integration` が **failure**、ステップ11 `check:schema` が failure。
**なぜ気づかなかったか**: `check:schema` / `check:allowlist` / `check:edge-types` は
psql・Docker・Deno を要し、**ローカルで原理的に実行できない**。
手元で回せる検査は全部緑だった。

> **「ローカルで回せる検査の集合 ≠ 完了判定に必要な検査の集合」** というずれが根。
> 対策は新しい規則ではなく、CLAUDE.md 常設指示「CI監視の定型化」の履行。

### 3-2. Prettier による破壊の正体

`~/.claude/settings.json:44` のグローバルフック `npx prettier --write . 2>/dev/null; true`。
`--write .` がリポジトリ全体を対象にするため、編集と無関係な
`pnpm-lock.yaml`（5061行）/ `env-diff.md` が書き換わっていた。**非冪等**で1回あたり
インデントが +4 押し下がり、表がコードブロックに飲まれる。
**グローバル設定なので Sentio 以外の全プロジェクトでも起きる。**

### 3-3. レガシー JWT キーの期限（`07_open_items` 登録済み）

- Edge Functions のゲートウェイ JWT 検証は **`anon` / `service_role` のレガシー JWT でしか動かない**
- そのレガシーキーは **2026年末に廃止予定**
- 本スライスで17本すべてから `--no-verify-jwt` を外した ＝ **レガシーに依存する設計**

移行時に何を担保に置き換えるかは**未判断**。

### 3-4. Google OAuth 審査 — スコープが過剰だった

Google から差し戻し。指摘は3点（デモ動画 / テスト資格情報 / プライバシーポリシー）。

**最重要**: Google は「なぜ narrower な権限が使えないのか説明しろ」と言っているが、
**実際には narrower で足りる。**

| スコープ                          | 意味                                             | 判定             |
| --------------------------------- | ------------------------------------------------ | ---------------- |
| `calendar.readonly`（現在要求中） | See and **download any calendar** you can access | **過剰**         |
| `calendar.events.readonly`        | **View events** on all your calendars            | **これで足りる** |

コードが叩く Google API は `GET /calendar/v3/calendars/primary/events` の**1本だけ**
（`callback/google/route.ts:137` と `sync-connections/index.ts:199`）。
`calendarList` / `calendars` / `acls` / `settings` は一度も呼んでいない。

**動画を撮り直す前にスコープを差し替える。** 順序を逆にすると撮り直しになる。

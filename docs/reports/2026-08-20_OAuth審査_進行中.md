## 2. スコープの変更（変更前 → 変更後）

### 変更内容

|            | スコープ                                                   | 意味（公式ドキュメント）                                             |
| ---------- | ---------------------------------------------------------- | -------------------------------------------------------------------- |
| **変更前** | `https://www.googleapis.com/auth/calendar.readonly`        | See and **download any calendar** you can access using your Calendar |
| **変更後** | `https://www.googleapis.com/auth/calendar.events.readonly` | **View events** on all your calendars                                |

**追加するスコープは無い。1本を狭いものに置き換えるだけ。**

### 変更の根拠（実測）

コードが叩いている Google Calendar API は **1エンドポイントのみ**。

| 場所                                               | 呼び出し                                    |
| -------------------------------------------------- | ------------------------------------------- |
| `src/app/auth/callback/google/route.ts:137`        | `GET /calendar/v3/calendars/primary/events` |
| `supabase/functions/sync-connections/index.ts:199` | `GET /calendar/v3/calendars/primary/events` |

`calendarList` / `calendars` / `acls` / `settings` は**一度も呼んでいない**。
したがって `calendar.readonly`（カレンダーそのものをダウンロードできる）は過剰。

### さらに狭いスコープを採らない理由

| スコープ                         | なぜ採らないか                                                                                             |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `calendar.events.owned.readonly` | 自分が**所有する**カレンダーの予定のみ。**招待された会議が落ちる**。会議負荷が Sentio の中核指標なので必要 |
| `calendar.freebusy`              | 空き時間ブロックのみで、件名・参加者数が取れない。分析が成立しない                                         |

**`calendar.events.readonly` が成立する最小のスコープ。**

### 変更が必要なファイル

| ファイル                                    | 現在                                                         | 変更後                                                  |
| ------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| `src/app/api/auth/google/route.ts:31`       | `scope: "https://www.googleapis.com/auth/calendar.readonly"` | `.../calendar.events.readonly`                          |
| `src/app/auth/callback/google/route.ts:101` | `scopes: ["calendar.readonly"]`                              | `["calendar.events.readonly"]`                          |
| Google Cloud Console の OAuth 同意画面      | `calendar.readonly`                                          | `calendar.events.readonly` に差し替え、旧スコープを削除 |

> Google はプライバシーポリシーの URL を**実際に取りに来る**。
> 改訂版が本番に出ていない状態で再提出すると、同じ指摘が返ってくる。

### 現時点の判定: ⛔ **再提出してはならない**

| 条件                                              | 現状                     | 判定       |
| ------------------------------------------------- | ------------------------ | ---------- |
| `https://sentio-ai.jp/privacy` が改訂版を返すこと | 旧版（2026-08-19）のまま | **不成立** |
| 改訂版が merge されていること                     | 未コミット・未 PR        | **不成立** |
| 改訂版が deploy されていること                    | 未デプロイ               | **不成立** |

**3条件すべて不成立。** 加えて、ポリシーに書いた削除仕様（24ヶ月 / 連携解除30日）が
未実装なので、**仮にデプロイしても記述と実態が食い違う**。

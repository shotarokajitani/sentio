# Sentio 顧客体験の全体設計と文面集（打診からマニュアルまで）（2026-09-09・Fable）

最初の10社が「打診を受けてから、有料で使い続けるか決めるまで」に触れるものを、順番に全部置きます。各段階に「目的／届くもの／測るもの／文面」を付け、最後に利用ガイド（マニュアル）・従業員向け案内・FAQ・サポート手順を置きます。文面はそのまま使える形で、実際にできることしか書いていません（未実装のものは「実装後に有効」と注記）。

コストの見立ては人日ではなく、変更ファイル数・部品数・運用費で書きます。

書かないこと: 会計ソフト連携（未公開）、Slack・Chatwork（未実装）、AI が判断する、といった手元に無いもの。

## 9〜10. 無料期間の終了

- 3日前: 実装済みの `trial_will_end` メール（招待の場合は「一時停止になります。お支払い方法を登録された時点で再開します」の文面に分岐。発注⑤で対応）。
- 期限当日: 画面に「無償期間が終了しました。お支払い方法を登録すると、翌朝から再開します」。メールは送らない（3日前に送っている。催促を重ねない）。
- 再開: カード登録の翌朝から通常どおり。再開初日のメール冒頭に「ご利用を再開いただき、ありがとうございます」。

## 11. 解約・削除

- 解約: 「プランと支払いを管理」→ Stripe のポータル。解約後も期間末まで届く。期間末の翌朝に「本日で配信を終了しました。データは連携解除から30日で削除します（詳細はプライバシーポリシー）」を1通。
- 削除依頼: support@ 宛。契約 DR の運用（受付→30日→削除→完了通知）。

## 12. 利用ガイド（マニュアル）— 「はじめての Sentio」

公開場所: `/guide`（ログイン不要）。A4 で3枚に収まる長さ。章立てと本文。

```
はじめての Sentio

1. Sentio は何をするものか
　毎朝7時に、会社の状態をまとめたメールを1通お送りします。
　つないだ情報（カレンダー・入出金）から「昨日の実績・今日の予定・お金の動き・定例の状態・変わった動き」を組み立てます。
　入力は要りません。読むだけです。

2. 始め方
　(1) 「Google カレンダーをつないで始める」を押す
　(2) 会社で使っている Google アカウントを選ぶ（求める権限は予定の読み取りだけ）
　(3) つないだ直後に、過去1年の会議の様子が画面に出る
　(4) 翌朝7時から毎朝メールが届く

3. 入出金を取り込む（任意・おすすめ）
　銀行のインターネットバンキングから入出金明細を CSV で保存し、画面の「入出金 CSV」にドロップします。
　取り込み後、「この振込先は自社の口座ですか？」と聞かれたら、当てはまるものを選んでください（自社間の振替を入出金から除くためです）。
　毎月1回、月初に前月分を取り込むと、定期の入金や支払いの到着が見えるようになります。

4. 毎朝のメールの読み方
　一番上の3行に、その日の状態をまとめています。忙しい日はそこだけで足ります。
　「変わった動き」があるときは、その項目に「対応した」「見送る」「これは通常です」のボタンが付きます。
　　対応した…その件を確認・対応した
　　見送る…今回は対応しない（次回以降も同じ種類の動きは出ます）
　　これは通常です…この動きは自社では普通のこと（次回以降、通常として扱います）
　押さなくても構いません。押すと、Sentio がその会社の「通常」を覚えていきます。

5. 週1回の「今週の会社」
　毎週月曜の朝に、1週間分をまとめたメールが届きます。定例の状態、時間の使い方、お金の動き、来週の予定が入っています。

6. ダッシュボード
　メールのリンクから開けます。メールに書いてあることの根拠（日付・題名・金額）を辿る場所です。
　過去のメールもここで読み返せます。毎日見に来る必要はありません。

7. 見ているもの・見ていないもの
　https://www.sentio-ai.jp/transparency にまとめています。社内の方にそのまま共有できます。

8. 料金とお支払い
　お申し込みから14日間は無料です（無償トライアルの場合は招待メールに記載の期日まで）。
　その後は月額30,000円（税込）。解約はいつでも「プランと支払いを管理」からできます。
　解約後も、お支払いいただいた期間の終了日までは届きます。

9. 連携が切れたとき
　Google 側で権限が取り消されると、翌朝のメールで「再連携のお願い」が届きます。
　メールのリンクから、もう一度 Google アカウントを選ぶだけで元に戻ります。

10. データの削除
　連携を解除すると、30日後に取り込んだデータを削除します。
　アカウントごと削除したい場合は support@mdc-diseno.com にご連絡ください。30日以内に削除し、完了をお知らせします。

11. 困ったとき
　support@mdc-diseno.com（平日 10:00〜18:00）。メールで承ります。
```

## 14. FAQ（公開・LP の「よくある質問」を拡張）

- カレンダーの内容は書き換えられますか → いいえ。求める権限は「予定の読み取り」だけです。
- 予定の詳細欄（メモ）は見ますか → 見ません。取得するのは日時・題名・出席者の人数と社内外の別だけです。
- 出席者のメールアドレスはどう扱いますか → 社内か社外かの判定にだけ使い、画面やメールには出しません。
- 社員に何かしてもらう必要はありますか → ありません。
- 会計ソフトとつながりますか → 現在は入出金の CSV 取り込みに対応しています。会計ソフトとの自動連携は準備中です。
- メールは誰に届きますか → 登録した経営者のメールアドレスだけです。
- 「変わった動き」が間違っていたら → 「これは通常です」を押してください。次回以降、通常として扱います。
- 解約するとどうなりますか → 「プランと支払いを管理」からいつでも解約できます。お支払いいただいた期間の終了日まで届きます。
- データはいつ消えますか → 連携解除から30日後に削除します。保存期間は最長24か月です。
- 無償トライアルの終了後、自動で課金されますか → されません。一時停止になり、お支払い方法を登録した時点で有料での利用が始まります。

## 16-2. セルフチェックの結果（2026-09-09・文面と実装の突合）

1. 打診文の「定期の入金や支払いの到着をお知らせ」は検知1（系列エンジン）の実装後にしか成立しないため、「入金と支払いの動きも同じメールに入ります」（発注③の範囲）に弱めた。
2. 招待メールの「つないだ直後に過去1年の会議の様子」は初回体験（別発注）の実装後に足す形に変更。
3. 「毎朝7時」＝dispatch-daily 22:00 UTC、「毎週月曜の朝」＝dispatch-weekly 日曜 23:00 UTC（月曜 08:00 JST）。cron と一致。
4. ガイドの「連携解除から30日で削除」は privacy の公開済み文言と同じだが、D-3 の実削除は 2026-10-08 以降の判断で据え置き中。**ローンチまでに D-3 を有効化しない場合は、ガイドとプライバシーポリシーの両方を実態に合わせる必要がある**（判断事項に追加）。
5. 「解約後も期間末まで届く」は Stripe の cancel_at_period_end 中は status が active のままなので、配信の関門（SENTIO_ENFORCE_ENTITLEMENT）を有効にしても成立する。

7. サポート時間「平日 10:00〜18:00」は /legal の表記と一致。

同じ意図が2つの式で書かれている。片方だけ直したときにずれる。

#### 追記（2026-08-28）— 実データで埋まることを本番で確認した

連携中の Google アカウント（`shotaro.kajitani@mdc-diseno.com`）のカレンダーに
当週の予定を2件作り、`invoke-function` で `sync-connections` を回した結果:

```
今週の会社
8月24日 〜 8月30日
会議        5件    比較できるだけの履歴がありません
総会議時間  5時間  比較できるだけの履歴がありません
のべ出席者  3人
今週の予定
  週次経営会議                8月24日 10:00–11:00
  新規パートナー商談（初回）  8月25日 14:00–15:30
  開発デイリー                8月26日 09:30–10:00
  顧客定例 — 導入レビュー     8月27日 13:00–14:00
  採用面談（1次）             8月28日 16:00–17:00   出席者 3人
```

**総会議時間が独立検算と一致した。** 作成時の設計値は
60 + 90 + 30 + 60 + 60 = **300分 = 5時間**。画面の「5時間」はこれと合う。
`summarizeWeek` の合算が実データでも正しいことの裏取りになっている。

**Google カレンダー → `sync-connections` → `events` → `/report` が端から端まで通った。**

| 確認 | 結果 |
| --- | --- |
| 時刻が JST で出る | 作成した 10:00–11:00 / 16:00–17:00 がそのまま出ている（UTC の 01:00 / 07:00 ではない） |
| 出席者の人数 | `採用面談` は主催者＋ゲスト2名で **3人**。`metrics.attendees` の要素数が効いている |
| メールアドレス | **画面に1件も出ていない**（W-2-1 が本番でも成立） |
| ゲスト無しの予定 | `週次経営会議` は出席者行そのものが出ない（0 のとき描かない） |

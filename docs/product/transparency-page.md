# Sentio 透明性ページ（従業員向けの1枚）の設計と文面（2026-09-09・Fable）

拡張案 D1・指針7の具体化です。spec/04「透明性ページ: 見ているもの・見ていないもの一覧を経営者・従業員双方が閲覧可能（3点開示の実装）」は設計にあって実装がありません。ここでは、ページの役割、費用と見込み、文面（そのまま使える形）を置きます。

---

## 1. 役割（判断）

1. 経営者が従業員に「入れました」と言うときに見せる1枚。口頭の説明を要らなくする。
2. 打診メール・LP から辿れる公開ページ。「監視ツールではない」を、言葉ではなく一覧で示す。
3. 連携が増えるたびに、このページの「見ているもの」が増える。**ページの更新が無いまま連携を増やさない**（コードとページを同じ辞書から出す）。

## 2. 費用と見込み（試算・仮定つき）

- 費用: 1〜2作業日（静的ページ1枚＋辞書＋連携カードとの共通化）。外部費用0円。
- 見込み: 直接の売上はゼロ。効くのは2か所。①打診の返信率（透明性ページのリンクの有無で比較。仮に返信率が10%→12%に上がれば、100社打診で＋2社の商談）②導入後の「従業員からの反発で解約」の回避（10社のうち1社でも防げれば年36万円）。1〜2日の費用に対して、どちらか一方でも起きれば回収できます。
- 測り方: リンクを付けた打診と付けない打診を50社ずつに分けて返信率を比べる（費用ゼロ）。

## 3. ページの構成

URL: `/transparency`（ログイン不要・LP のフッターと打診メールから）。
見出しは経営者の語彙ではなく、**従業員が読む前提の言葉**にする。

1. 見出し: 「Sentio が見ているもの、見ていないもの」
2. 一文: 「Sentio は、日報や報告会議を減らすための仕組みです。皆さんに入力をお願いすることはありません。」
3. 見ているもの（連携ごとに1行。連携していないものは「まだ見ていません」と明示）
4. 見ていないもの（構造上取れないもの。強調して置く）
5. 誰に届くか
6. Sentio が出さないもの
7. 質問の窓口

## 4. 文面（そのまま使える案）

```
Sentio が見ているもの、見ていないもの

Sentio は、日報や報告会議を減らすための仕組みです。
会社で使っているツールから「いつ・何が・どれくらい」の記録だけを受け取り、
毎朝、経営者に会社の状態をまとめて届けます。
皆さんに入力をお願いすることはありません。

見ているもの
　Google カレンダー　予定の日時・題名・出席者の人数と社内外の別
　　　　　　　　　　　（出席者のメールアドレスは、社内か社外かの判定にだけ使い、画面やメールには出しません）
　入出金の記録　　　　日付・金額・相手先・残高
　会計ソフト　　　　　まだ見ていません
　メッセージ　　　　　まだ見ていません
　勤怠　　　　　　　　まだ見ていません

見ていないもの
　・メールやチャットの本文、件名、添付ファイル
　・予定の詳細欄（メモ・議事録）
　・個人ごとの成績や順位
　・皆さんの端末やブラウザの操作

誰に届くか
　毎朝のメールと週1回のまとめは、経営者だけに届きます。
　届くのは「会社全体」と「取引先ごと」の動きです。
　個人の名前を挙げて評価する文章は、仕組みとして作れないようにしています。

Sentio が出さないもの
　Sentio は、個人を評価したり、順位づけしたりする情報を出しません。
　従業員の方について経営者に届くことがあるとすれば、
　「最近やり取りが減っている方がいるので、声をかけてみてはどうですか」という形だけです。
　導入企業には、Sentio を人事評価や勤務の監視に用いないことをお願いしています。

質問があるとき
　support@mdc-diseno.com（株式会社ディセーノ）まで。会社を通さずに直接お送りいただけます。

最終更新: 2026年9月9日
```

## 5. 実装の要点

1. 「見ているもの」の行は、`/connect` の連携カードと**同じ辞書**から生成する（連携先を足すとこのページも自動で増える。片方だけ更新される状態を作らない）。
2. 「見ていないもの」は allowlist（S2 禁止列）と対応させ、試験で「allowlist に無い項目をページに『見ていない』と書いていない」「allowlist の禁止項目がページに載っている」を固定する。
3. 「まだ見ていません」は連携の有無ではなく**製品として提供していない**ことを指す。会社ごとの連携状態は載せない（公開ページなので）。会社ごとの状態は、ログイン後のダッシュボードの「見えているもの」節が担う。
4. メールのフッターと LP のフッターに「Sentio が見ているもの・見ていないもの」のリンクを置く。
5. 窓口の「会社を通さずに直接」は、従業員が経営者に知られずに質問できる経路を意味する。運用上は support@ に来た従業員からの質問を、経営者に転送しない扱いにする（DR-1 の窓口運用に1行足す）。

## 6. 判断が要ること（梶谷さん）

1. 従業員からの質問を経営者に共有しない運用でよいか（ページにそう書く以上、守る必要があります）。
2. 「Sentio が出さないもの」の文面（2026-09-09 に修正済み）。「人事評価に使わない」は導入企業の行為なので Sentio が言い切れず、Sentio が制御できる「個人を評価・順位づけする情報を出さない」に直し、企業側の使い方は依頼の形に留めた。
